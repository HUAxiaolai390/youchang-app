# 有常 v2.9.2

## 本次更新

- 修复从手机通知栏将临时任务改到明天后，今日计划仍显示原任务的问题。
- 按通知点击当天计算改期日期，跨过午夜后重新打开应用也不会多推迟一天。
- 防止完成、跳过、改期通知重复到达时把任务状态反转或重复创建。
- 忽略任务日期已经被编辑后的旧通知，避免旧提醒覆盖新安排。
- 通知操作改为“保存成功后确认”：应用保存失败、切到后台或重启时，未处理操作会留在手机队列中并自动重试。
- 应用启动时先同步待处理通知操作，再刷新下一批提醒，减少旧提醒重复出现。

## 安装

下载下方 APK 并在安卓手机上安装即可。更新安装不会主动清除本地任务；升级前仍建议在“设置 → 备份与恢复”导出一次备份。
