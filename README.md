# 有常

有常是一款把每日固定任务、临时安排、专注计时和成长记录放在一起管理的本地小应用。数据保存在你正在使用的浏览器里，不需要注册账号。

## 专注与成长

首页提供专注/休息倒计时，可一键选择 25/5、50/10，也可以自定义分钟数。完成一轮专注后会累计专注次数、总时长和经验值，小猫会播放庆祝动作；“成长”页会显示当前等级和升级进度。成长页顶部还内置了 31 条带中英文和作者的励志名言，每个本地日期自动更换一句，断网时也可以正常显示。

## 正计时与时间分配

专注卡片可以在“倒计时”和“正计时”之间切换。正计时结束后，可以把时间追加到今天的某项任务，也可以只选择学习、工作、运动、休息等分类单独记录。每项今日任务和待安排任务旁都有“用时”按钮，可以手动填写或修改实际花费的分钟数；填写 0 会清除该任务的用时。成长页的“时间分配”支持查看今天和近七天的分类占比。

## 每周复盘

成长页会按周一到周日自动汇总本周完成进度、预计与实际用时、主要时间投入分类。可以填写“本周总结”和“下周调整”，每项最多 500 字；每一周的内容独立保存，并可以查看最近三次历史复盘。清空两项内容后保存会删除本周复盘。

## 长期目标

成长页可以创建带截止日期的长期目标，例如“通过英语六级”。新增或编辑任务时，可以选择关联某个目标；目标卡片会根据关联任务显示完成进度、累计实际投入时间和距离截止日期的天数。删除目标不会删除已有任务，只会解除任务与目标的关联。分类表示任务属于学习、工作等哪种类型，长期目标表示完成任务最终是为了什么。

## 固定任务习惯详情

首页固定任务旁的“趋势”可以打开这项习惯自己的记录。详情会显示当前连续次数、最长连续次数、近 30 天完成率、累计实际投入时间和每日完成日历。连续次数只按照实际需要完成的日期计算，周末、暂停和主动跳过的日期不会打断纪录。

## 周计划、月历与计划用时

底部“计划”页可以在周视图和月视图之间切换。周视图显示本周一到周日；月视图可以浏览前后月份，并用完成比例和逾期标记展示每天的情况。点击任意日期可以查看当天任务，并直接添加或编辑任务。任务会先按优先级、再按开始时间排列，同时汇总预计用时和实际用时。筛选栏可以组合选择优先级、任务分类和完成状态；筛选后的日期数量与用时统计会同步更新，并可一键清除筛选。未完成的临时任务可以从周视图直接改到本周其他日期，原来的改期记录仍会保留。旧任务和旧备份没有这些字段时也能继续正常使用。

## 任务提醒

任务填写开始时间后，可以选择准时或提前 5、10、30、60 分钟提醒。有常打开时会显示应用内提醒；设置中开启系统通知后，还会显示电脑通知。同一天内即使错过了原定时间，重新打开有常也会补充提醒。提醒卡片可以直接完成任务，或选择 5、10、30 分钟后再次提醒；临时任务可以直接改到明天，固定任务可以只跳过当天这一次。

首页的“提醒中心”会把提醒分为“即将开始”“已错过”和“已推迟”。默认保持折叠，只显示各类数量；展开后可直接完成任务、延后 10 分钟、改到明天或跳过固定任务当天这一次。

安卓系统通知还提供同样的快捷操作：临时任务可直接完成、延后 10 分钟或改到明天；固定任务可完成、延后 10 分钟或跳过今天。操作会在有常运行时自动同步到任务记录，即使点击通知操作后没有重新打开页面也会及时更新。

在“设置 → 通知权限”中打开“免打扰时间”，可以设置夜间等静默时段。普通任务提醒会在该时段暂停，专注完成和休息结束提醒仍会照常发送；关闭后恢复全部任务提醒。

## 小猫动画

首页的小猫会随当天任务状态变化：没有任务时睡觉，有待完成任务时待机；它会每隔一段时间自己随机更换动作，也可以点击切换到下一个待机动作，共有 18 种；完成任务或一轮专注后会优先庆祝。系统开启“减少动态效果”时，小猫会自动改用对应动作的静态 PNG 图片，不播放 GIF 动画，也不会自动切换。

小猫素材和背景音乐从用户提供的程序中为这个本地个人版本提取，仅限个人使用。若要公开分发、发布或用于其他项目，请先替换为原创或已获得相应授权的素材。

## 桌面一键启动（推荐）

第一次使用时，仍需在项目文件夹的终端中运行 `pnpm install`，准备有常需要的工具。完成后，再运行下面这条命令安装桌面快捷方式：

```powershell
pwsh.exe -NoProfile -File .\scripts\install-desktop-shortcut.ps1
```

命令会在桌面创建“启动有常”。以后正常使用时，直接双击桌面的“启动有常”即可：它会在后台启动本地服务，并自动打开浏览器，不需要先打开 VS Code 或保留一个终端窗口。

如果启动失败，提示信息会说明常见原因。只有排查问题时才需要查看项目文件夹下的 `.youchang\logs` 日志；平时无需操作这个文件夹。如果以后移动了整个项目文件夹，请回到新的项目位置重新运行上面的快捷方式安装命令。

## 在 VS Code 中打开

打开 VS Code，点击“文件”→“打开文件夹”，选择这个项目文件夹。打开后，点击顶部菜单“终端”→“新建终端”，终端会出现在窗口下方。

第一次使用时，在终端中依次运行：

```powershell
pnpm install
pnpm dev
pnpm check
```

`pnpm install` 用来准备项目需要的工具。检查所需的 Chromium 浏览器也会由项目自动准备；如果安装阶段没有下载，它会在 `pnpm check` 开始时自动完成，因此不需要再运行其他准备命令。第一次下载浏览器可能需要多等一会儿。

`pnpm dev` 启动应用后，终端会打印一个本地地址；按住 Ctrl 点击这个地址，或把它复制到浏览器地址栏，就能打开有常。开发服务会一直运行并占用当前终端。需要运行 `pnpm check` 时，请在 VS Code 中再打开一个终端；也可以先在开发服务所在的终端按 Ctrl+C 停止服务，再运行检查。

`pnpm check` 会检查类型、自动化测试、生产构建、桌面端流程、手机端流程和离线能力。看到所有检查通过后，说明当前版本可以正常使用。

## 数据和备份

任务、完成记录、分类和设置保存在当前浏览器的本地存储中。换一个浏览器、换一个本地地址，或清除浏览器网站数据时，原数据不会自动跟过去。

需要留存或迁移数据时，打开应用底部的“设置”，在“备份与恢复”中点击“导出备份”。浏览器会下载一个 JSON 备份文件，请把它保存到安全的位置。以后可以在同一区域选择“导入备份”，核对摘要并确认后恢复。

## 关于手机应用

有常同时提供可安装的 PWA 和独立安卓版本。独立安卓版本不依赖浏览器、公开网址或 ChatGPT 账号，数据只保存在安装它的手机中。运行 `pnpm android:apk` 会同步最新网页代码、应用图标和启动画面，并把测试安装包生成到 `outputs/youchang-android-test.apk`。

把电脑数据迁移到安卓版本时：先在电脑版“设置 → 备份与恢复”中导出 JSON 备份，把文件发送到手机；再打开安卓版本的同一区域，选择“导入备份”，核对摘要后确认。导入完成前不要卸载电脑版或清除原浏览器数据。

PWA 版本仍然保留：使用手机打开安全的 HTTPS 地址后，可以从“设置 → 安装到手机”查看对应设备的安装入口或步骤。Android 浏览器会在支持时显示“安装有常”；iPhone 需要使用 Safari 的“分享 → 添加到主屏幕”。

电脑与手机目前各自保存数据，不会自动同步。当前 APK 使用安卓调试签名，适合个人试装；准备给同学分发或上架应用商店前，需要再生成并妥善保存正式签名。
