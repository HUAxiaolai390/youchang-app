# 有常

有常是一款把每日固定任务和临时安排放在一起管理的本地小应用。数据保存在你正在使用的浏览器里，不需要注册账号。

## 小猫动画

首页的小猫会随当天任务状态变化：没有任务时睡觉，有待完成任务时待机；点击小猫会短暂互动，完成任务后会庆祝。系统开启“减少动态效果”时，小猫会自动改用静态 PNG 图片，不播放 GIF 动画。

小猫素材从用户提供的程序中为这个本地个人版本提取，仅限个人使用。若要公开分发、发布或用于其他项目，请先替换为原创或已获得相应授权的素材。

## 在 VS Code 中打开

打开 VS Code，点击“文件”→“打开文件夹”，选择这个项目文件夹。打开后，点击顶部菜单“终端”→“新建终端”，终端会出现在窗口下方。

第一次使用时，在终端中依次运行：

```powershell
pnpm install
pnpm dev
pnpm check
```

`pnpm install` 用来准备项目需要的工具。检查所需的 Chromium 浏览器也会由项目自动准备；如果安装阶段没有下载，它会在 `pnpm check` 开始时自动完成，因此不需要再运行其他准备命令。第一次下载浏览器可能需要多等一会儿。

`pnpm dev` 启动应用后，终端会打印一个本地地址；按住 Ctrl 点击这个地址，或把它复制到浏览器地址栏，就能打开有常。开发服务会一直运行并占用当前终端。需要运行 `pnpm check` 时，请在 VS Code 中再打开一个终端；也可以先在开发服务所在的终端按 Ctrl+C 停止服务，再运行检查。

`pnpm check` 会检查类型、自动化测试、生产构建、桌面端流程、手机端流程和离线能力。看到所有检查通过后，说明当前版本可以正常使用。

## 数据和备份

任务、完成记录、分类和设置保存在当前浏览器的本地存储中。换一个浏览器、换一个本地地址，或清除浏览器网站数据时，原数据不会自动跟过去。

需要留存或迁移数据时，打开应用底部的“设置”，在“备份与恢复”中点击“导出备份”。浏览器会下载一个 JSON 备份文件，请把它保存到安全的位置。以后可以在同一区域选择“导入备份”，核对摘要并确认后恢复。

## 关于手机应用

现在不需要安装或配置 Capacitor。有常目前以浏览器中的 PWA 运行，支持安装到桌面和离线打开；等以后确实需要打包原生手机应用时，再引入 Capacitor。
